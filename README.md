# cesoi.de

Personal portfolio of Cesar Barbosa — 3D animator, designer and lookdev artist based in São Paulo.

🌐 Live site: [cesoi.de](https://cesoi.de)

## Stack
- Static HTML/CSS — no build step
- Hosted on GitHub Pages
- Custom domain via GoDaddy DNS

## Structure
```
/
├── index.html              # Home / Works / About
├── *.html                  # Individual case study pages
├── shared.css              # Cesoi design system — global tokens
├── colors_and_type.css     # Cesoi design system — colors & type scale
├── hero-bg.png             # Home hero background
├── cesar-portrait.jpg      # About portrait
└── assets/                 # Case study media (images, videos, GIFs)
```
